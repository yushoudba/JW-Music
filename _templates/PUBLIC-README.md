# JW-Music

耶和華見證人詩歌：**主旋律 + 左手伴奏**五線譜（PNG）。

旋律依官方主旋律譜；左手為個人練習編配，僅供個人練習分享。

工作區在私有庫 `JW-Work/音樂/`；本庫為公開鏡像。同步指令：`音樂/scripts/publish-music.ps1`。
